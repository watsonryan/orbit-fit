# orbitfit-plots

Publication figures from native orbit-fit outputs, using Matplotlib and SciencePlots. The C++23 library and CLI remain independent of this optional package. Python performs no fitting or SGP4 propagation.

From the repository root, with [uv](https://docs.astral.sh/uv/getting-started/installation/):

```sh
uv sync --locked --project tools/plots --python 3.12
uv run --locked --project tools/plots orbitfit-plot fit docs/figures/input \
  --qualification docs/benchmarks/2026-10-24-iss-comparison-macos-arm64.csv \
  --output-dir figures
```

Use a new output directory. This works without a native build using the gallery's checked-in native input pair. For your own fit, pass the CLI results directory instead of `docs/figures/input`.

See the [plotting guide](../../docs/plotting.md) for input contracts, statistics, exact dimensions, fonts, failure handling, and reproducibility, and the [gallery](../../docs/figures/README.md) for the figures and their provenance. Python 3.12–3.14 is supported. `pyproject.toml` pins direct dependencies and `uv.lock` records the full resolution with archive hashes; the lock is generated by uv and retains its machine-readable form. The root Apache-2.0 license covers this authored package. Dependencies retain their upstream licenses.

```sh
uv run --locked --project tools/plots ruff check tools/plots
uv run --locked --project tools/plots ruff format --check tools/plots
uv run --locked --project tools/plots python -m unittest discover -s tools/plots/tests -v
```

Poppler's `pdffonts` and `pdfinfo` enable the PDF font/page audit; that test is skipped when the tools are absent. CI installs them. `uv.lock` was produced with uv 0.10.9, the version pinned in CI. CMake and CPM do not discover or install this environment.
