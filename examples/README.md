# Examples

## Complete CLI input

[request.json](../examples/request.json) is a complete `orbit-fit.request.v1` input. It contains 61 synthetic TEME position/velocity samples, spaced two minutes apart from `2026-01-01T00:00:00Z` through `2026-01-01T02:00:00Z`. Positions are in metres; velocities are in metres per second. Catalog number `99999` and object name `SYNTHETIC EXAMPLE` identify synthetic data and must be replaced when preparing a real object's request.

From the repository root, after building:

```sh
build/release/orbit-fit fit --input examples/request.json --output-dir results
```

The output directory must not exist. A successful fit exits with code 0 and writes `elements.tle`, `elements.omm.json`, `report.json`, and a copy of the request. The example requires a position RMS of at most 10 m for the continuous fit and both reparsed products. No element seed or measurement covariance is supplied; the default approximation weights and automatic initialization apply. See the [input contract](../docs/input.md) for required fields, options, and acceptance semantics.

The main fields are:

| Field | Purpose |
|---|---|
| `schema` | Selects the versioned request format |
| `frame`, `time_system` | Explicitly declare TEME states and UTC timestamps |
| `metadata` | Identifies the object in TLE/OMM products |
| `fit.start`, `fit.stop` | Select the inclusive fitting window |
| `fit.epoch` | Sets the fitted mean-element epoch |
| `fit.maximum_rms_position_m` | Sets the physical acceptance threshold |
| `samples` | Ordered epochs with `position_m` and `velocity_mps` vectors |

The fixture was generated by watson using the native `orbit-fit example` command and the unmodified Vallado propagation path. It is a runnable format/integration example, not independent tracking data. JSON does not permit comments, so its description and authorship live here. Generate another copy without changing the checked-in fixture:

```sh
build/release/orbit-fit example --output request.json
```

## C++ API examples

- [fit.cpp](../examples/fit.cpp): synthetic fitting and shared product validation.
- [forecast.cpp](../examples/forecast.cpp): fitting the frozen NASA ISS forecast and checking held-out predictions.
- [cancellation.cpp](../examples/cancellation.cpp): cooperative cancellation and result handling.

The C++ examples compile and run under CTest. The CLI example test also fits the checked-in request and checks acceptance of its continuous fit, OMM, and TLE.
